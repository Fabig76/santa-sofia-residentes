📐 Wireframe Sección 3 v2.1 — Fix estético

Santa Sofía Club Residencial V.I.S · 16-Sep-2026 · Comparativa ANTES vs DESPUÉS
🔄 Problema reportado: "los recuadros se ven desalineados no se ve algo estetico".
Causa raíz: Grid CSS `1fr 1fr 1fr 1.4fr 0.8fr 1fr` generaba anchos desbalanceados (Apto 88px vs Nombre 154px = 75% diferencia). Labels con alturas variables (1 línea, 2 líneas, 3 líneas) hacen que los asteriscos * queden a alturas distintas. Select (38px) vs input (36px) genera diferencia sutil.

  • .row.row-6: grid `1fr 1fr 1fr 1.4fr 0.8fr 1fr` → repeat(6, minmax(115px, 1fr)) (uniforme, mínimo 115px por columna)
  • .field label: agregar min-height: 32px; display:flex; align-items:flex-start; gap:3px (asterisco a misma altura)
  • inputs/selects: agregar height: 38px explícito (elimina diferencia 36/38px)
  • .autoriz-row: padding `14px → 18px`, gap `12px → 14px` (más respirado)
  • Labels acortados: "N° Parqueadero que autoriza" → "N° Parqueadero", "Tipo de vehículo" → "Tipo", "Placa del vehículo autorizado" → "Placa autorizado", "Nombre del autorizado" → "Nombre autorizado" (caben en 1 línea, * alineado)
